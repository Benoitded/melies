# Raccourcis

## Global

| Raccourci | Action |
|---|---|
| Cmd+Shift+E (réglable) | Ouvrir l'éditeur sur la dernière vidéo du Bureau |

## Éditeur (style Shottr)

| Raccourci | Action |
|---|---|
| Espace | Lecture / pause |
| I / O | Point d'entrée / de sortie du trim |
| Gauche / Droite | Image précédente / suivante |
| Shift+Gauche / Droite | 10 images |
| Cmd+C | Exporter en MP4 Twitter et copier le fichier |
| Cmd+S | Exporter en MP4 Twitter et enregistrer à côté de l'original |
| Cmd+Shift+O | Ouvrir un fichier |
| Cmd+Shift+V | Charger une vidéo depuis le presse-papiers |
| Esc | Fermer |

À venir (v2) : outils flèche (A), texte (T), rectangle (R), spotlight, blur (B),
zone de zoom (Z), Cmd+Z / Cmd+Shift+Z, Cmd+D pour dupliquer.

Les raccourcis Shottr réels de l'utilisateur n'ont pas pu être lus (macOS
bloque l'accès au conteneur de Shottr). À compléter depuis une capture de ses
Préférences.
