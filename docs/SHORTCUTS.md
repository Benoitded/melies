# Raccourcis

## Global

| Raccourci | Action |
|---|---|
| Cmd+Shift+6 (réglable) | Démarrer l'enregistrement (on dessine la zone), puis le même raccourci l'arrête |
| Cmd+Shift+E (réglable) | Ouvrir l'éditeur sur la dernière vidéo du Bureau |

Pendant l'enregistrement, tout ce qui est hors de la zone est assombri (et absent
de la vidéo), et un bouton rouge `■ 0:07` apparaît dans la barre de
menu : un clic arrête et ouvre l'éditeur sur la vidéo. 
Choix de la zone : glisser pour dessiner, **Espace maintenu** pour déplacer le
rectangle sans le redimensionner (comme macOS et Shottr), Esc pour annuler.

## Éditeur (style Shottr)

| Raccourci | Action |
|---|---|
| Espace | Lecture / pause |
| I / O | Point d'entrée / de sortie du trim |
| Gauche / Droite | Image précédente / suivante |
| Shift+Gauche / Droite | 10 images |
| Z | Zoom animé : crée un zoom (début + fin), puis ajoute un point à la position de lecture |
| Suppr | Supprimer le point de zoom sélectionné |
| V / A / T / R / S / B | Outils : sélection, flèche, texte, rectangle, spotlight, flou |
| Suppr / Retour arrière | Supprime l'objet sélectionné (annotation ou point de zoom) |
| C | Recadrer l'image (poignées, Entrée pour valider, Esc pour annuler) |
| Cmd+C | Exporter en MP4 Twitter et copier le fichier |
| Cmd+S | Exporter en MP4 Twitter et enregistrer à côté de l'original |
| Cmd+Shift+O | Ouvrir un fichier |
| Cmd+Shift+V | Charger une vidéo depuis le presse-papiers |
| Cmd+, | Ouvrir les Réglages |
| Esc | Fermer |

À venir (v2) : outils flèche (A), texte (T), rectangle (R), spotlight, blur (B),
zone de zoom (Z), Cmd+Z / Cmd+Shift+Z, Cmd+D pour dupliquer.

bloque l'accès au conteneur de Shottr). À compléter depuis une capture de ses
Préférences.
