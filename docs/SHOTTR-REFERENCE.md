# Shottr reference

We take over usage conventions (shortcuts, flow), not the code, name,
icon or text of Shottr.

## Flow

Capture, the editor opens right on it, everything is done from the keyboard,
then copy or save and close. Lightweight window, compact toolbar.

## Shottr shortcuts adopted or adapted (public docs)

This lists Shottr's conventions, not what Melies has today. What Melies implements is in `docs/SHORTCUTS.md`: among
the items below, Cmd+Z / Cmd+Shift+Z, Cmd+S, Cmd+C, Cmd+O (open), Cmd+Shift+V, Return to confirm the crop, and the
canvas zoom shortcuts (Cmd+1, Cmd+0, Cmd+plus / minus) exist; Cmd+D, Option+drag to duplicate, Cmd+Shift+S, and the
oval, counter, magnifier, ruler and color picker tools do not.

- Zoom: Cmd+1 fit, Cmd+0 100%, Cmd+plus / minus, Z, pan with Space+drag
- Selection: Enter confirms the crop, Shift+drag square, arrows 1 px,
  Shift+arrows 10 px
- Editing: Cmd+Z / Cmd+Shift+Z, Cmd+C / V / D, Opt+drag duplicates
- File: Cmd+S saves, Cmd+Shift+S save as, Cmd+Shift+O open,
  Cmd+Shift+V load from the clipboard
- Tools: arrow, text, rectangle, oval, spotlight, blur, counter,
  magnifier, ruler, color picker

## What we add for video

Timeline with trim, an export panel (MP4, HEVC or GIF, target size, resolution; ratio and fps corrected for
Twitter / X), animated zooms (manual or from recorded clicks), annotations with a duration and object tracking,
side-by-side and picture-in-picture, a drag handle for the result.
